# Слухайко

Плеєр для аудіокниг з Telegram. Працює в браузері на iPhone та Android, встановлюється на головний екран як застосунок.

- Плейлист: кілька файлів за раз, автоматично по черзі (сортування за назвою: Частина 1, 2, 3…)
- Продовження з місця зупинки для кожного файлу
- Швидкість 0.5×–3× з кроком 0.25
- Перемотка −15 / +30 с, таймер сну, керування з екрана блокування
- Файли зберігаються локально в телефоні (IndexedDB), нікуди не завантажуються
- Працює офлайн після першого відкриття (service worker)

## Структура

```
index.html             весь застосунок (HTML + CSS + JS)
manifest.webmanifest   опис для встановлення на головний екран
sw.js                  офлайн-кеш; змінюйте VERSION при кожному релізі
icons/                 іконки
```

## Локальний запуск

У VS Code: розширення **Live Server** → правий клік на `index.html` → *Open with Live Server*.
Або: `npx serve .` / `python -m http.server 8000`.

Щоб перевірити з телефону в тій самій Wi-Fi мережі, відкрийте `http://<IP-компʼютера>:8000`
(service worker на http працює лише на localhost, але сам плеєр працюватиме).

## Публікація на GitHub Pages

1. Створити репозиторій `slukhaiko` на GitHub і запушити файли.
2. *Settings → Pages → Source: Deploy from a branch → main / root*.
3. Через хвилину плеєр доступний за `https://<username>.github.io/slukhaiko/`.

## Встановлення на телефон

- **iPhone (Safari):** відкрити посилання → «Поділитися» → «На початковий екран».
- **Android (Chrome):** відкрити посилання → «⋮» → «Встановити застосунок» / «Додати на головний екран».

## Як додати книгу з Telegram

- **iPhone:** утримати аудіофайл → «Поділитися» → «Зберегти у Файли». Потім у Слухайку «Додати файли».
- **Android:** «⋮» біля файлу → «Зберегти в завантаження» (папка `Download/Telegram`). Потім «Додати файли».

## Оновлення

Після змін у файлах збільшіть `VERSION` у `sw.js` (`v1` → `v2`), інакше телефони можуть показувати стару версію з кешу.
